CODAST작업 인계 실험UI DEMO

같은 작업, 두 가지 시작 방식

자료에서 다음 작업까지

로그인 화면과 요구사항을 연결하고, 결과를 검토한 뒤 테스트 케이스를 도출해 보세요.

예시 결과를 보여주는 시뮬레이션입니다. 파일 내용 분석, AI 호출, 서버 저장·전송은 하지 않습니다.

이번 작업

    입력 자료

    체험 방법
    1. 자료 추가 아이콘을 눌러 예시 자료를 채웁니다.
    2. 첫 분석을 시작하고 연결 결과를 검토합니다.
    3. 검토한 결과로 테스트 케이스를 만듭니다.
    4. 완료 후 다른 안도 체험해 봅니다.

    두 안의 결과는 같습니다. 작업을 준비하고 넘기는 과정만 비교합니다.

    2. 테스트 케이스 도출

    전달할 작업 지시서
    선택한 자료와 버전, 사용자 지시를 묶습니다. 실제 에이전트에게 전송하지 않습니다.
    

    자료 확인
    

    체험 기록
    이 탭에서 완료한 체험만 집계합니다. 실제 AI의 속도나 품질을 측정한 A/B 실험은 아닙니다. 새로고침하면 기록이 초기화됩니다.
    시간은 첫 조작부터 완료까지 화면이 보이는 동안의 경과 시간입니다. 다른 안으로 전환하거나 탭이 숨겨진 시간은 제외합니다. 조작 수는 등록·선택·검토·전송 등 의미 있는 동작을 셉니다. 키 입력 수는 세지 않습니다.
