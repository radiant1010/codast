## 산출물

로컬 산출물은 `outputs/`에서 확인합니다. 이 폴더는 저장소에 포함되지 않으므로 새로 복제한 환경에서는 없을 수 있습니다. 현재 구현·검증 범위는 [클라이언트 연동 기록](client-runtime.md)과 [TODO](TODO.md)에 남깁니다.

## 관리 규칙

- 문서를 추가·이동하면 이 인덱스와 관련 링크를 함께 갱신합니다.
- 계획과 체크 상태는 TODO, 결정 이유는 단계별 기록, 완료 결과는 산출물 보고서에 기록합니다.
- 완료 보고서는 당시의 결과입니다. 이후 구현이 달라지면 새 보고서를 추가하고 인덱스에서 최신 결과를 안내합니다.
- 산출물은 `outputs/`에 두고 산출물 인덱스에 날짜·목적·검증 상태를 등록합니다. 파일이 많아지면 작업별 하위 폴더로 묶습니다.
- 산출물·임시 파일·실행 DB는 Git에서 제외합니다. 재사용할 설계·결정·검증 요약만 docs에 기록합니다. 임시 로그·렌더링 중간 파일·테스트 작업 폴더는 `work/`에 둡니다.
- 실제 프로젝트의 생성 코드는 해당 Workspace의 `generated/` 등 프로젝트 경로에 유지합니다. 하네스 자체의 보고서·전달 파일과 구분합니다.
