# 구현 노트

세션 관리와 실행 복구, 첨부 자료 처리에서 다룬 주요 문제와 구현 근거를 정리합니다. 상세 동작은 [세션과 실행 동작](client-runtime.md), 남은 작업은 [개발 계획](TODO.md)을 참고하세요.

전체 계층과 위임 관계는 [오케스트레이션과 실행 하네스의 책임 경계](harness-architecture.md)를 참고하세요.

## 문제 정의와 설계 판단

사용자가 AI 결과를 해석하고 다음 담당에게 지시서를 만드는 부담에서 출발했습니다. 단계별 작업 계약과 산출물 인계, 검증 후 진행, 필요한 사용자 개입과 재개를 제품의 핵심으로 정리했습니다. 공식 자료에서 가져온 원칙과 대안, 선택 이유는 [설계 근거](orchestration-design.md)에 있습니다.

아래 표는 구현과 검증 기록이 있는 기반 기능입니다. 다단계 자동 진행과 생산성 개선은 아직 검증할 목표이며, 세션 복구에 성공했다는 사실만으로 전체 워크플로 복구나 비용 절감을 주장하지 않습니다. 프로젝트를 소개할 때도 구현한 범위와 앞으로 확인할 가설을 구분합니다.
