# 작업 지시서 예시

아래는 실제 업무 자료를 사용하지 않는 가상 예시다. 대상과 버전, 허용 범위와 완료 조건을 작업에 맞게 작성한다.

```text
작업 ID: EXAMPLE-001
목표: 메모 API의 최대 입력 길이를 200자에서 300자로 변경한다.
입력: 승인된 가상 메모 API 명세 v2, 현재 코드와 테스트.
허용 범위: 등록한 프로젝트 폴더의 메모 API 구현과 관련 테스트.
유지 조건: 기존 데이터와 API 응답 형식은 유지한다.
제외 범위: 인증, 삭제 기능과 배포는 이번 작업에 포함하지 않는다.

검증 조건:
- 300자 입력은 허용하고 301자 입력은 거절한다.
- 공백만 있는 입력은 거절한다.
- 변경 전에 저장한 메모를 조회할 수 있다.
- 서버 재시작 후에도 데이터가 유지된다.

명세에서 결정할 수 없는 정책은 구현 전에 질문한다.
완료 시 변경 파일, 변경 이유, 실제 검사 명령과 결과,
미검증 범위와 남은 제약을 보고한다.
```
