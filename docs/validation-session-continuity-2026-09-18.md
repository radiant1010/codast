# 실제 세션 연속성 검증 — 2026-09-18

실제 설치된 CLI와 모델 응답을 사용했다. Codex CLI 0.155.0-alpha.2.6, Claude Code 2.1.273, Windows 및 Edge headless 환경이다. 기존 작업실과 별개인 로컬 검증 서버·SQLite DB·프로젝트에서 읽기 전용 요청을 보냈다. 인증 저장소를 복제하지 않았고 도구 실행이나 파일 수정을 요청하지 않았다. 원문 응답·실제 세션 ID·검증 DB·실행 경로는 Git 제외 영역에만 보관한다.

## 결과

| 검사 | 결과 |
| --- | --- |
| Codex 신규 실행 | 성공 응답과 네이티브 세션 ID 수신 |
| Codex 재개 | 같은 세션 ID, resumed=true, 첫 요청에서 지정한 임의 표식 재현 |
| 이름 변경 후 실제 서버 프로세스 종료·재기동 | 고유 채팅 ID와 네이티브 세션 유지, 재개 후 동일 표식 재현 |
| 동일 요청 ID 재전송 | 기존 실행 ID 반환, 실행 수 증가 없음 |
| 기록 보존 | 해당 채팅의 요청·결과 3건 유지 |
| 사용량 | 성공 실행의 usage 수신 확인. 캐시 의미·과금 정확성까지 검증한 것은 아님 |
| 실제 API 연결 브라우저 | 다른 채팅 전환·복귀 시 초안과 원래 결과 3건 유지, 새로고침 후 복원, JavaScript 오류 없음 |
| Claude 신규 실행 | 로그인 필요 오류로 실패. 재개·서버 재시작 검증 미수행 |

Codex 검증은 실제 모델 요청 3회, Claude는 인증 실패 요청 1회다. 동일 요청 재전송에서 추가 모델 실행이 없음을 저장된 실행 수로 확인했다. 검증용 서버는 종료했으며 기존 작업실 서버는 재시작하거나 설정을 변경하지 않았다.

## 남은 범위

Claude는 사용자 CLI 로그인 이후 같은 흐름을 검증해야 한다. 실제 CLI 작업 중 강제 종료·취소·SSE 단절, 장시간 작업, 다른 작업 경로·권한으로의 전환, 원본 CLI에서 직접 재개, DB 백업·복원은 이번 실제 실행 검사에 포함하지 않았다. 이 중 일부는 기존 모의/자동 검사만 통과한 상태다. 컨텍스트 압축·전체 대화 보존 또는 실제 실행 모델 수집을 이 결과로 보장하지 않는다.
